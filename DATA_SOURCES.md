# Audited dataset sources

The repository contains metadata audits and aggregate diagnostics only.
It does not redistribute any source image, video, mask or label archive.
Each dataset retains its own licence; the table below records the source
and licence statement used by the audit.

| Dataset | Source | Licence noted by the audit |
|---|---|---|
| AppleGrowthVision | https://datacloud.hhi.fraunhofer.de/s/KLFXDw9cWSzXk95 | CC BY 4.0 |
| TomatoMAP | https://doi.org/10.5447/ipk/2025/14 | CC BY 4.0 |
| LettuceMOTS | https://github.com/NanH5837/LettuceMOTS | Original data licence not explicit; code GPL-3.0 |
| WeedsGalore | https://doidata.gfz.de/weedsgalore_e_celikkan_2024/ | CC BY 4.0 |
| PlantWild | https://huggingface.co/datasets/uqtwei2/PlantWild | CC BY-NC-ND 4.0 |
| WE3DS | https://doi.org/10.5281/zenodo.7457983 | CC BY 4.0 |
| CropAndWeed | https://github.com/cropandweed/cropandweed-dataset | Custom non-commercial licence |
| PhenoBench | https://www.phenobench.org/dataset.html | CC BY-SA 4.0 on the current official page; bundled older README differs |
| Crops3D | https://github.com/clawCa/Crops3D | CC BY 4.0 |

The full extracted source statements are in `data/provenance.txt`.  A
mirror's dataset card is not a substitute for the original licence.
PhenoBench has conflicting licence statements between the live official
page and an older bundled README; consult the source before redistribution.
